## 📦 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install --legacy-peer-deps
```

### Running Locally
```bash
npm start
```
The site will run on [http://localhost:3000/Portfolio_](http://localhost:3000/Portfolio_).

### Building for Production
```bash
npm run build
```

### Deploying to GitHub Pages
```bash
npm run deploy
```
